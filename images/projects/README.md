# Project Screenshots

Add your project screenshots here with these filenames:

- `asr.jpg` - ASR (Automatic Speech Recognition) System screenshot
- `nid.jpg` - Electronic NID Registration System screenshot
- `pos.jpg` - Grocery POS System screenshot
- `shebank.jpg` - SheBank Hackathon Project screenshot
- `research.jpg` - Academic Research project screenshot

## Image Guidelines

- **Format**: JPG or PNG
- **Dimensions**: 800x600px or 1200x900px (4:3 ratio recommended)
- **Size**: Keep under 500KB for fast loading
- **Content**: Show the main interface or key features of each project

## How to Add Images

1. Take screenshots of your projects
2. Resize/crop them to 800x600px or similar
3. Compress them using tools like:
   - TinyPNG (https://tinypng.com)
   - Squoosh (https://squoosh.app)
4. Save them in this folder with the exact filenames above

If an image is missing, the card will automatically hide the image area and show just the text.
